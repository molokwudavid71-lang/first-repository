# Email simulator

A simple Python program that simulates how an email system works. It runs in the terminal and does not connect to a real email account.

## Features
- Check your inbox and read messages
- Send an email to another user
- Receive emails from other users

## Built with
- Python
- Functions
- Imported modules
- If-else statements

## How to run it
1. Install Python from python.org
2. Download `Email_simulator.py` from this repository
3. Open a terminal in the same folder and run:
   `python Email_simulator.py`
4. Follow the menu on screen to check your inbox, send, or receive emails
